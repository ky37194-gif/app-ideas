# 💡 App Ideas Tracker

Save app ideas, track their stage and progress, plan features (MVP / Later), and keep a work journal.

- **Website:** https://ky37194-gif.github.io/app-ideas/
- **Android app:** `android/` (WebView wrapper, build with `bash android/build.sh <device-serial>`)
- **Data:** saved in the browser/app (localStorage). Optional sync between devices via a secret GitHub Gist (Dashboard → Sync).

Everything is in a single file: `index.html` (plain HTML + CSS + JavaScript).
